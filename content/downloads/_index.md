## Dokumente im Schulportal

Einige Dokumente werden zentral im Thüringer Schulportal gepflegt. Diese können direkt extern verlinkt werden:

[Dokumente der Staatlichen Grundschule Schönstedt im Schulportal öffnen](https://www.schulportal-thueringen.de/schools/documents?tspi=802)

Wenn sich die Schulportal-Adresse ändert, muss nur dieser Link angepasst werden.

## Vorgesehene Dokumente

- aktuelle Elternbriefe
- Schulanmeldung und Hinweise für Schulanfänger
- Hortinformationen
- Essensplan oder Essenszeiten
- Ferienangebote
- Informationen zur Schülerbeförderung
- Formulare für Änderungen von Kontaktdaten

Die Dateien können später im Repository abgelegt und hier direkt verlinkt werden. Alternativ können externe Dokumente, die bereits im Schulportal gepflegt werden, direkt verlinkt werden.
